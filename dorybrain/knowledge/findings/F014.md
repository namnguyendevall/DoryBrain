# F014: Exploration-Induced Premature Termination

## Context
During the analysis of Batch 0013 (E014: Experience Replay), I discovered a critical flaw in the previous analysis of Batch 0012 (E013: TD-Learning). I had previously assumed that because the `steady_state_work_rate` was ~0.18, the agent was surviving its entire 10,000 tick lifetime and perfectly learning to survive. 

**This was factually incorrect.** 

A closer inspection of the `survival` metric for both E013 and E014 reveals that the agents are actually dying at **tick ~15 to 20** across almost all environmental conditions. 

## The Real Failure Mechanism
The agents are failing because of a **Protocol Failure** (Exploration-Induced Premature Termination), rather than a fundamental barrier of the learning architecture itself.

1. **The Epsilon Trap**: The agents use an $\epsilon$-greedy exploration schedule that decays from 1.0 to 0.05 over the first 3,000 ticks. 
2. **Lethal Randomness**: In these Phase 4/5 environments, resources decay constantly. If an agent acts randomly (as it must during the early phase of $\epsilon$-greedy learning), it frequently chooses invalid or sub-optimal actions, causing it to starve within the first 20 ticks.
3. **Premature Death**: Because the agent dies at tick ~15, its "single lifetime" ends almost immediately. 
4. **Learning is Precluded**:
   - For E013, it never has the 9,998 ticks to learn $V(State_1)$. It dies during exploration.
   - For E014 (Experience Replay), the replay buffer is configured to only start replaying when it reaches 100 transitions. Because the agent dies at tick 15, **offline replay is literally never triggered**.

## Conclusion
Batch 0012 and 0013 failed to validate their core hypotheses (Bootstrapping Barrier and Experience Replay) because the learning protocol itself did not allow the agents to survive long enough to learn. Before evaluating advanced learning mechanisms, the exploration protocol must be fixed (e.g., via Action Masking for safe exploration) to ensure the agent can actually accumulate a meaningful lifetime of experience.
